# 你以為的數位世代

TIGPS（臺灣數位世代青少年的成長歷程追蹤研究）開放日手機互動遊戲。玩家選身分與年齡區間後作答，每題揭曉 TIGPS 的真實數據；結束時顯示自己的成績，以及現場參加人次、身分、年齡分布與平均答對率。

- `index.html`：遊戲本體（單一檔案，題目與數據都在裡面）。
- `index.html#live`：大螢幕用的即時統計頁，每 30 秒自動更新。
- `apps-script/Code.gs`：統計用的 Google Apps Script，資料存在 Google 試算表。

## 會記錄哪些資料

只記錄：時間、隨機產生的場次代碼、開始／完成、玩法、身分、年齡區間、答對題數、題數、各題對錯。
不蒐集姓名、電話、Email、IP 或裝置資訊。

## 部署步驟

### 1. 建立統計用的試算表與 Apps Script（約 5 分鐘）

1. 用計畫的 Google 帳號建立一份新的 Google 試算表，例如命名為「開放日遊戲統計」。
2. 在試算表選單點「擴充功能 → Apps Script」。
3. 把編輯器裡原本的內容全部刪掉，貼上 `apps-script/Code.gs` 的內容，按儲存。
4. 點右上角「部署 → 新增部署作業」：
   - 類型選「網頁應用程式」
   - 執行身分：「我」
   - 誰可以存取：「所有人」
5. 按「部署」，第一次會要求授權，依畫面允許。
6. 複製「網頁應用程式」網址（`https://script.google.com/macros/s/……/exec`）。

### 2. 把網址填進遊戲

打開 `index.html`，找到這一行：

```js
const API_URL = "";
```

把剛剛複製的網址貼進引號中間，存檔。沒有填網址時，遊戲照樣可以玩，只是不會統計。

### 3. 上架到 GitHub Pages

1. 在 GitHub 新增一個 **Public** repository，例如 `tigps-openday-game`。
2. 上傳 `index.html`、`README.md` 和 `apps-script` 資料夾。
3. 到 repository 的「Settings → Pages」，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約 1～2 分鐘後，網址會是 `https://<帳號>.github.io/<repository 名稱>/`。
5. 用這個網址產生 QR code（任何 QR code 產生器都可以）。大螢幕開 `https://<帳號>.github.io/<repository 名稱>/#live`。

### 4. 活動前測試

1. 用手機玩一次快速挑戰，結果頁應該會出現「現場大家玩得怎麼樣？」的統計。
2. 打開試算表的 `log` 工作表，確認有新的資料列。
3. 測試完把 `log` 工作表第 2 列以後的測試資料刪掉（保留第 1 列標題），統計就會歸零。

### 修改 Apps Script 之後

改了 `Code.gs` 要重新部署：「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」。這樣網址不會變，不用改 `index.html`。

## 統計怎麼算

- **參加人次**：按下開始挑戰的人數；親子默契挑戰算 2 人次。
- **完成挑戰**：玩到結果頁的人數。
- **平均答對率**：每位完成者「答對題數 ÷ 題數」的平均，所以快速挑戰（8 題）和完整版（31 題）可以放在一起比較。
- **你贏過幾 % 的參加者**：以答對率比較。
- **最多人猜錯的題目**（大螢幕頁）：至少 3 人作答過的題目中，答對率最低的 6 題。
